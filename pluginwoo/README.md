## ✨ امکانات

### 🛒 سبد خرید حرفه‌ای
- **۴ چیدمان**: پیش‌فرض، مدرن، مینیمال، سایدبار
- جدول محصولات با کنترل количества (，并列 بهبود یافته)
- جمع‌يابي فشرده در سایدبار
- badge تخفیف و وضعیت انبار روی هر محصول
- دکمه‌های کاهش/افزایش و حذف آیتم با انیمیشن

### 📝 صفحه صورت‌حساب
- **۴ چیدمان**: پیش‌فرض، مدرن، مینیمال، سایدبار
- فرمeyer با استایل حرفه‌ای و گسترده
- جمع‌يابي سفارش در بخش رنگی کناری/پنل
- شرط‌ها و پرداخت‌ها با طراحی مدرن

### 👤 پنل ناحیه کاربری
- **۳ چیدمان**: پیش‌فرض، مدرن، مینیمال
- دکمه «ناحیه کاربری» در هدر با هماهنگی با ووکامرس
- داشبورد با آمار سفارشات، میانگین خرید و جمع کل
- جدول سفارشات با وضعیت‌های رنگی
- کارت خوش‌آمدگویی شخصی‌سازی شده

### 🛍 المان‌های اختصاصی محصول
- **کروسول (`carousel`)**: کاروسل افقی با اسکرول خمیده + دکمه‌های پیش/بعد
- **اسلایدر (`slider`)**: اسلایدر افقی با هر محصول در اسلاید کامل
- **شبکه‌ای (`grid`)**: ۱ تا ۴ ستونه، کاد بسیار با افکت هابر
- **لیست (`list`)**: لیست افقی با تصویر، توضیحات و قیمت
- هر کدام با چیدمان و استایل متفاوت، قابل انتخاب از طریق شورت‌کد

### 🎨 المان بنر و پوستر
- **بنر پیش‌فرض**: تصویر بک‌گراند + رویه نیمه شفاف + عنوان + دکمه
- **بنر خلاقانه**: کاد خلاقانه با گریديه تصویر و محتوا + افکت پالس پس‌زمینه + افکت شناور
- **پوستر**: تابلوی 본딩 تصویر + متن پایین + badge روی تصویر + افکتglow

### 🛍 المان بنر محصول
- **بنی روی محصول (`product-banner-default`)**: دیو two-column با تصویر Boone و اطلاعات + badge تخفیف
- **خلاقانه (`product-banner-creative`)**: دیو دوستونی با خط زنده کناری + افکت نئون پس‌زمینه + افکت شاین هنگام هاور

### ✨ افکت اضافه شدن به سبد خرید
- **پروانه پروازی (`fly`)**: تصویر محصول پروانه می‌شود به آیکون سبد خرید — افکت کلاسیک
- **باز۶ میوه (`bounce`)**: تصویر به سمت بالا پرتاب شده و می‌پرد 〜 bounce
- **پالس انرژی (`pulse`)**: افکت انرژی با تداعی‌های دایره‌ای
- فعال/غیرفعال در تنظیمات → همگی با AJAX و تو د یا بی‌تدا

### 🏠 هدر و فوتر
| هدر | فوتر |
|-----|------|
| پیش‌فرض | پیش‌فرض |
| مدرن (gradient) | مینیمال (کج) |
| مینیمال (ساده) | — |
| خلاقانه (با جستجو + لوگو آیکون) | — |

### 🎪 صفحه فروشگاه خلاقانه
- تیتر و متن تبلیغاتی در بالا با گرادینت
- نوار دسته‌بندی‌ها (category strip) به صورت اسلاید ان제품명
- بب 아라 필터 و مرتب‌سازی
- شبکه ۳-۴ ستونه با آیکون‌ها اضافه شدن، badge‌ها و افکت هاور
- paginação notation

### 📄 صفحه محصول
- **مدرن**: گالری تصویر + تابلو اطلاعات چیده‌شده‌ی کناری — کامل و حرفه‌ای
- **خلاقانه**: دوستونی تصویر + اطلاعات با خط کناری رنگی + حالت‌های توضیحات/ویژگی‌ها/نظرات

### 🚀 یکپارچگی تلگرام
- ارسال خودکار محصول جدید به کانال تلگرام هنگام ایجاد (`woocommerce_new_product`)
- ارسال تصویر + نام + قیمت + توضیحات کوتاه به فرمت Markdown
- پشتیبانی از توکن ربات (@BotFather) + شناسه کانال
- ارسال پیام خ 판매시 از انبار (`woocommerce_product_set_stock`)
- سازگاری با بازو‌های بله‌وبز/بلاگ‌وبز با ربات تلگرامی

### 📱 ناو موبایل (모발ای ناو)
- ناو ناو در پایین صفحه است به جای فوتر در موبایل (حدود ۷۶۸px)
- ۵ آدرس: خانه، فروشگاه، سبد خرید (با شمارش دان)، اکانت، تماس
- آیکون‌های SVG با標記 فعال بودن صفحه
- افکت هاور و پس‌زمینه آبی برای آیتم فعال
- body padding-bottom برای جلوگیری از پوشش محتوا

### ⚙️ تنظیمات پیشخوان وردپرس
- پنل تنظیمات با ۳ بخش: قالب‌های آماده، شخصی‌سازی بصری، افکت‌ها و یکپارچگی‌ها
- گزینه‌های رنگی (primary, secondary, accent) با پیکر رنگ
- انتخاب فونت (وزیرمتن، شبنم، یکان‌بخش، لزوار، وزیر)
- انتخاب چیدمان برای: سبد خرید، صورت‌حساب، پنل کاربری، هدر، فوتر، صفحه فروشگاه، صفحه محصول
- فعال/غیرفعال افکت سبد خرید و انتخاب نوع آن
- فعال/غیرفعال ناو موبایل
- تنظیمات تلگرام (توکن + شناسه کانال)
- ورودی CSS اختصاصی (inline style)
- دکمه ذخیره با آیکون قلب + بازه‌ی نسخه

### 🎨 قالب‌های اختصاصی
- تمامی قالب‌های مورّد در `templates/` با ساختار و استایل مستقل

## 🚀 نصب

1. پوشه `pluginwoo/` را در `wp-content/plugins/` کپی کنید.
2. وارد پanel مدیریت وردپرس شوید → پلاگین‌ها → نصب شده‌ها.
3. **PluginWoo** را فعال کنید.
4. به `Settings → PluginWoo` بروید و تنظیمات را تغییر دهید.

یا از طریق SSH:
```bash
cd wp-content/plugins/
# کپی پوشه pluginwoo/
wp plugin activate pluginwoo
```

## 🧩 شورت‌کدها

| شورت‌کد |Attr‌های اصلی| توضیحان |
|----------|-------------|----------|
| `[pluginwoo_cart]` | `template="modern"` | سبد خرید با قالب مشخص |
| `[pluginwoo_checkout]` | `template="modern"` | صورت‌حساب با قالب مشخص |
| `[pluginwoo_myaccount]` | `template="modern"` | پنل کاربری |
| `[pluginwoo_product_display]` | `type="carousel\|slider\|grid\|list"`, `ids=""`, `category=""`, `per_page="8"`, `columns="4"`, `template="default"` | المان نمایش محصول |
| `[pluginwoo_banner]` | `banner_id=""`, `template="default\|creative\|poster"`, `link=""`, `height="400"` | المان بنر |
| `[pluginwoo_product_banner]` | `product_id=""`, `template="default\|creative"` | المان بنر محصول |
| `[pluginwoo_store_page]` | `template="creative\|modern\|default"` | صفحه فروشگاه |
| `[pluginwoo_product_page_alt]` | `product_id=""`, `template="modern\|creative"` | صفحه محصول جایگزین |
| `[pluginwoo_header]` | `template="modern\|default\|minimal\|creative"` | هدر |
| `[pluginwoo_footer]` | `template="modern\|default\|minimal"` | فوتر |
| `[pluginwoo_mobile_nav]` | — | ناو موبایل (جایگزین فوتر) |

## 🎨 نحوه استفاده

### نمایش کروسول محصول
```
[pluginwoo_product_display type="carousel" per_page="10" columns="4"]
```

### نمایش بنر خلاقانه
```
[pluginwoo_banner banner_id="123" template="creative" link="https://example.com/sale" height="400"]
```

### المنت بنر محصول
```
[pluginwoo_product_banner product_id="99" template="creative"]
```

### نمایش شبکة محصولات
```
[pluginwoo_product_display type="grid" category="电子产品، كتاب" per_page="12" columns="3"]
```

### ناو موبایل
```
[pluginwoo_mobile_nav]
```

## 🐛 رفع اشکال

| مشکل | راه‌حل |
|------|--------|
| قالب‌ها نمایش داده نمی‌شوند | مطمئن شوید قالب در تنظیمات انتخاب شده و فایل template وجود دارد |
| افکت سبد خرید کار نمی‌کند | jQuery را بررسی کنید که لود شده باشد؛ AJAX URL در تنظیمات درست است |
| تلگرام پیام نمی‌فرستد | توکن ربات را از `@BotFather` و شناسه کانال را از `@GetIDsbot` دریافت کنید |
| ناو موبایل نمایش داده نمی‌شود | در تنظیمات «ناو موبایل» را فعال کنید و از مرورگر موبایل تست کنید |
